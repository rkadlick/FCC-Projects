# 📝 Random Quote Machine  
A simple React app that generates random quotes and allows users to tweet their favorite ones. Built with React, TailwindCSS, and a public quotes API.

## Overview
The Random Quote Machine is a project inspired by FreeCodeCamp's frontend development curriculum. It fulfills all user stories to display random quotes, fetch new ones, and allow users to share them on Twitter.

## Features
- 🌟 Displays a random quote and its author on page load.  
- 🔄 Fetches a new random quote when the "New Quote" button is clicked.  
- 🐦 Allows users to share the current quote on Twitter with a single click.  
- 📱 Fully responsive design for mobile and desktop.  
- 🎨 Styled with TailwindCSS for a clean and minimalistic appearance.  

## Built With
- **Frontend Framework:** [React](https://reactjs.org/)  
- **Styling:** [TailwindCSS](https://tailwindcss.com/)  
- **Quote API:** [Quotes REST API](https://api.quotable.io/random)  
- **Tooling:** Node.js, npm

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v14 or higher)  
- npm (v6 or higher)

### Installation
1. **Clone the repository:**
   ```
   git clone https://github.com/rkadlick/FCC-Projects/FE_Libraries/random-quote-machine.git
   cd random-quote-machine
  ```
2. **Install dependencies:**
    ```
    npm install
    ```
3. **Run the app:**
    ```
    npm start
    ```

## Usage
1. On app load, a random quote is displayed.
2. Click the "New Quote" button to fetch another random quote.
3. Share the current quote on Twitter by clicking the "Tweet" button.
