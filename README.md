# FreeCodeCamp Projects

This repository houses a collection of projects built as part of the FreeCodeCamp learning paths.  Currently, it contains projects demonstrating proficiency in React, Redux, and other front-end technologies.  This repository is designed to be expandable, allowing for the addition of more projects and potentially other FreeCodeCamp certifications in the future.

## Current Projects

This section showcases the completed FreeCodeCamp Front End Libraries projects.

### FreeCodeCamp Front End Libraries

This sub-directory contains a collection of individual React projects, each focusing on specific aspects of front-end development.

*   **[React Calculator](./FE-Libraries/):** A simple calculator web application built with React and Decimal.js.
*   **[Drum Machine](./FE-Libraries/):** A drum machine built using React, TypeScript, and Vite.
*   **[React Pomodoro Clock](./FE-Libraries/):** A Pomodoro Clock built using React to improve focus and productivity.
*   **[Markdown Previewer](./FE-Libraries/):** An interactive Markdown Previewer built using React, Redux, and TypeScript.
*   **[Random Quote Machine](./FE-Libraries/):** A React app that generates random quotes and allows users to tweet them.
